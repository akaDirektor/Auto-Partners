# АвтоПартнери

Незалежний застосунок для двох партнерів: автомобілі, фінанси, обговорення та приватний вхід за email і паролем. Акаунт ChatGPT не потрібен.

## Що входить

- Спільні автомобілі та коментарі, загальний чат, оновлення кожні 8 секунд.
- 20 марок, 939 назв моделей за 2006–2026 роки, двигуни для 933 моделей, базові кольори. Двигуни об’єднані за різними роками й ринками; довідник може мати пропуски.
- Розрахунок вкладень і прибутку; мінімальна, цільова й фактична ціни продажу.
- Два акаунти. Власник додає партнера в розділі «Доступ для партнера» й може змінити паролі.
- CSV та JSON-експорт даних. Захист від перезапису одночасних правок.

## Перший запуск на хостингу

Потрібен хостинг із Docker або Node.js 24, HTTPS і постійним диском. Один запущений екземпляр застосунку використовує одну локальну SQLite-базу. Статичний хостинг без сервера та постійного диска не підходить.

1. Розмістіть вихідний код або зберіть Docker-образ із Dockerfile.
2. Підключіть постійний диск до `/data`.
3. Установіть змінні середовища:
   - `PUBLIC_URL` — фактична HTTPS-адреса застосунку, без кінцевого слеша.
   - `OWNER_EMAIL` — email власника.
   - `OWNER_NAME` — ім’я власника.
   - `OWNER_PASSWORD` — унікальний пароль із 12–128 символів.
   - `DATABASE_PATH=/data/auto-partners.sqlite`.
   - `NODE_ENV=production`.
   - `PORT` — порт хостингу, типово 3000.
4. Запустіть застосунок. Перший запуск створює власника. Після цього видаліть `OWNER_PASSWORD` зі змінних середовища: обліковий запис уже зберігається в базі.
5. Увійдіть і створіть акаунт партнера через «Доступ для партнера». Запрошення поштою не надсилається: передайте партнеру адресу, email і початковий пароль особисто.

Перевірка доступності: `GET /api/health`.

## Локальний запуск

Потрібен Node.js 24 або новіший.

```sh
npm ci
npm run build
```

Скопіюйте `.env.example` у `.env`. Для локальної перевірки встановіть `NODE_ENV=development`, `PUBLIC_URL=http://localhost:3000`, `DATABASE_PATH=./data/app.sqlite` та власні email і пароль.

```sh
npm start
```

Адреса: http://localhost:3000. Для локальної розробки фронтенду в іншому терміналі виконайте `npm run dev`; сервер API має працювати на порту 3000.

## VPS із Docker

У `.env` вкажіть фактичні значення. `compose.yaml` публікує порт лише на localhost; підключіть HTTPS через reverse proxy вашого хостингу.

```sh
docker compose up --build -d
```

Не видаляйте volume `auto_partners`: у ньому база даних. Резервні копії диска налаштовуються у вибраному хостингу. Перед перенесенням SQLite-файлу зупиніть застосунок або використайте штатну SQLite backup-команду.

## Перенесення записів із попереднього застосунку

Перенесення самого коду не переносить віддалену базу автоматично. Після отримання актуального JSON-експорту з полями `cars` і `messages`, створіть власника в новій базі та імпортуйте:

```sh
node --env-file-if-exists=.env scripts/import-data.mjs export.json
```

Імпорт зберігає ID, версії, тексти й відображувані імена авторів. Попередні технічні ідентифікатори користувачів прив’язуються до нового власника. Перед імпортом зробіть копію бази. Повторний імпорт не дублює записи, але не перезаписує вже наявні ID.

## Перевірки

```sh
npm run typecheck
npm test
npm run build
```

Інтеграційні перевірки охоплюють два акаунти, спільні дані й повідомлення, приватність API, одночасне редагування, збереження після перезапуску, вихід, обмеження спроб входу й відкликання сесій після зміни пароля.

Це пакет для самостійного розміщення. Він не опублікований на незалежному хостингу, не містить робочих паролів, бази з реальними записами чи доступу до інфраструктури ChatGPT. Попередній сайт залишається окремим застосунком.
