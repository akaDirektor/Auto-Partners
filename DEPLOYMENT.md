# Підготовка HTTPS-версії

Цей коміт зберігає перевірену локальну версію React + Node.js 24 + SQLite.
GitHub Pages не виконує Node.js і не зберігає SQLite: не публікуйте лише dist як робочу спільну версію.

Наступний етап: адаптер Supabase Auth, Postgres із RLS для двох дозволених користувачів, атомарне оновлення за версією запису та серверне керування акаунтами. Зберегти дизайн, каталог і розрахунки. Далі налаштувати Vite base /Auto-Partners/ і workflow GitHub Pages.

Для хмарної конфігурації потрібен окремий проєкт Supabase: Project URL і publishable key (або legacy anon key). Це публічні параметри; секретний service_role ключ у фронтенд і репозиторій додавати не можна. Паролі задаються через захищені форми або локальне приватне налаштування.

Публічний репозиторій містить лише код і довідник. Реальні записи, чати, SQLite-файли, .env, сесії та тестові паролі не входять до коміту.
